الشروط والخصوصية

صاحبي تجربة مجانية للأصحاب، للبالغين ١٨+ فقط، وليس خدمة طبية أو قانونية أو مالية. الردود قد تخطئ أو تتوقف. الحد ٢٠ طلبًا يوميًا لكل متصفح وعنوان IP؛ الشبكات المشتركة تتشارك الحد. فودافون كاش متاح بتحويل يدوي، بدون بوابة أو تأكيد دفع تلقائي. مو يؤكد وصول المبلغ لمحفظته قبل التفعيل. خطة بلس ٣٠٠ جنيه لكل ٣٠ يوم، ٦٠٠ طلب وبحد يومي ٣٠ وميزانية ٥٠٠ ألف توكن إدخال و١٥٠ ألف إخراج، وتنتهي عند أول حد. التفاصيل وسياسة الاسترداد في نافذة الخطط، ولا تلغي الحقوق القانونية. لم تتم مراجعة الشروط قانونيًا.

المحتوى يُرسل إلى Google للتحليل عبر Gemini API المجاني، وقد يُستخدم للتحسين ويراجعه بشر. Cloudflare يستضيف الخدمة ويعالج بيانات الاتصال. بلاش بيانات حساسة أو ملفات لا تملك حق استخدامها. لا نحفظ المرفقات في تخزين خاص بالتطبيق؛ معالجة Google وسياسات احتفاظها مستقلة. المتصفح يحفظ نص المحادثة ومعرّفًا عشوائيًا واللغة والموافقة؛ زر محادثة جديدة يمسح النص المحلي. الخادم يحفظ عدادات الاستخدام ومعرّف المتصفح وبصمة مشفرة لعنوان IP لمدة محدودة، والحساب يحتفظ باسم مستخدم وبصمات مشفرة لمفاتيحه وبيانات الخطة وطلبات الدفع ومراجع التأكيد حتى الحذف، وقد يحتفظ مو بسجلات المعاملات اللازمة للمحاسبة أو النزاعات حسب القانون. جلسة الدخول ٧ أيام. لا بريد إلكتروني أو هاتف. زر حذف الحساب يمسح الحساب والجلسات والخطة وطلبات الدفع؛ السجلات التشغيلية ونسخ الاستعادة لدى المستضيف قد تبقى حسب سياسته. كود الاسترداد هو طريق الاستعادة الوحيد إذا فقدت مفتاح الدخول.
